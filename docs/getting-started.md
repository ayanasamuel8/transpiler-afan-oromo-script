# Getting Started

Welcome to OromScript! This guide will help you install and run your first OromScript program.

## Installation

You can install OromScript locally for development:

```bash
git clone https://github.com/ayanasamuel8/transpiler-afan-oromo-script.git
cd transpiler-afan-oromo-script
pip install -e .
```

## Running a Program

Create a file named `hello.orm` with the following content:

```python
agarsiisi("Akkam, Addunyaa!")
```

Then run it using the OromScript CLI:

```bash
oromscript run hello.orm
```
