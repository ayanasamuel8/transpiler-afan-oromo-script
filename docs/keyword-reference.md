# Keyword Reference

OromScript maps Afan Oromo words to standard Python constructs. Below are some of the fundamental keywords:

## Core Keywords
- `dhugaa` -> `True`
- `sobaa` -> `False`
- `wanti_hin_jirre` -> `None`
- `hojii` -> `def`
- `gosa` -> `class`

## Control Flow
- `yoo` -> `if`
- `yookaan` -> `elif`
- `yoo_miti` -> `else`
- `hanga` -> `for`
- `yeroo` -> `while`
- `addaan_kut` -> `break`
- `itti_fufuu` -> `continue`
- `deebi` -> `return`

## Modules & Exceptions
- `fidi` -> `import`
- `yaali` -> `try`
- `dogoggora` -> `except`
- `ol_kaasi` -> `raise`

## Built-in Functions
- `agarsiisi` -> `print`
- `gaafadhu` -> `input`
- `dheerina` -> `len`
- `barruu` -> `str`
- `lakki` -> `int`

*(See `adapters/afan_oromo/keyword_map.json` for the comprehensive schema list).*
