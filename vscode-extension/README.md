# OromScript

OromScript is a transpiler that allows you to write Python using syntax in your local language (Afan Oromo).

This extension provides syntax highlighting for `.orm` files.

## Features

- Syntax highlighting for Afan Oromo (`.orm`) source files.
- Reuses Python syntax for non-keyword elements.

## Requirements

No special requirements. Open an `.orm` file and it will be highlighted.

## Extension Settings

There are currently no extension settings available.
